O AutoProctor disponibiliza um painel de uso dedicado que mostra exatamente como seus créditos estão sendo consumidos. Você pode acompanhar o uso por teste e, se fizer parte de um time, por membro do time.

## Como os Créditos Funcionam

Os créditos são adicionados à sua conta quando você cria uma assinatura, quando ela é renovada, ou quando você adquire recargas de Pacotes de Testes. Cada vez que um candidato inicia um teste, um crédito é deduzido. A página de Uso oferece uma visão clara de para onde esses créditos vão.

## Visualizando o Uso dos Seus Créditos

{% stepper %}
{% step %}
### Abra a página de Uso
Clique na aba **Usage** na barra lateral esquerda.

![Link de Uso destacado na barra de navegação lateral esquerda](../../images/pricing/usage-sidebar-link.png)
*Link de Uso na barra lateral*
{% endstep %}
{% step %}
### Revise a tabela de uso
Você verá uma tabela mostrando a quantidade de créditos utilizados por teste. Clique no título de qualquer teste para abrir os resultados de todas as tentativas desse teste.

![Tabela de uso exibindo créditos consumidos por teste](../../images/pricing/usage-table.png)
*Tabela de uso*
{% endstep %}
{% endstepper %}

{% hint style="info" %}
Se um teste foi compartilhado com vários administradores de testes, apenas o **administrador principal (o criador do teste)** o verá listado na sua página de uso.
{% endhint %}

## Uso do Time

Se você faz parte de um [Time](pricing-account/billing-teams/teams.md), a página de uso mostra seus dados de testes pessoais por padrão. Para ver o consumo de créditos de todo o time:

{% stepper %}
{% step %}
### Clique em Team Usage
Clique no botão **Team Usage** no canto superior direito da página de Uso.
{% endstep %}
{% step %}
### Revise o consumo de todo o time
A visualização de uso do time exibe uma tabela com **todos os membros do time e a quantidade total de créditos que cada membro utilizou**. Clique em qualquer membro para ver em detalhe o uso por teste individual.

![Tabela de uso do time mostrando consumo de créditos por membro do time](../../images/pricing/team-usage-table.png)
*Tabela de uso do time*
{% endstep %}
{% endstepper %}

{% hint style="info" %}
Apenas os Administradores do Time e o próprio membro podem ver o uso detalhado por teste. Membros regulares do time podem ver a visualização resumida mas não os detalhes individuais de outros membros.
{% endhint %}
