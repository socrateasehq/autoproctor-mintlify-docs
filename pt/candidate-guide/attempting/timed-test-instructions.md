description: "Instruções essenciais para candidatos realizando um teste cronometrado (sem supervisão) no AutoProctor, incluindo ordem dos botões de envio, configuração de conta Google e teste de demonstração."
---

Os testes cronometrados no AutoProctor aplicam um temporizador de contagem regressiva ao seu questionário sem ativar a supervisão por câmera ou microfone. Mesmo que a supervisão não esteja ativa, as regras dos botões de envio ainda se aplicam — você deve clicar nos botões na ordem correta para salvar suas respostas.

{% hint style="warning" %}
Para questionários que não são do Socratease, você deve clicar nos botões de envio na ordem correta. Se você pular o botão roxo, **todas as suas respostas serão perdidas** e não poderão ser recuperadas.
{% endhint %}

## Faça o Teste de Demonstração Primeiro

Antes do seu teste real, confirme que sua configuração funciona fazendo a demonstração.

{% stepper %}
{% step %}
### Abra o link do teste de demonstração
Acesse [o teste de demonstração cronometrado do AutoProctor](https://www.autoproctor.co/tests/start-test/cQAtQHp7Jz/) no dispositivo e navegador que você planeja usar para o seu teste real.
{% endstep %}
{% step %}
### Complete a demonstração
Siga as instruções na tela para confirmar que o temporizador e a interface do questionário carregam corretamente.
{% endstep %}
{% step %}
### Solucione problemas se necessário
Se a demonstração carregar mas seu teste designado não, saia de todas as suas contas Google em [accounts.google.com/Logout](https://accounts.google.com/Logout) e tente novamente.
{% endstep %}
{% endstepper %}

{% hint style="info" %}
Se o teste de demonstração carregar com sucesso no seu dispositivo, qualquer teste que seu administrador designar a você também carregará.
{% endhint %}

## Botões de Envio

Para questionários que não são do Socratease (Google Forms, Microsoft Forms, etc.), existem **dois botões de envio** que você deve clicar na ordem correta:

1. **Botão Roxo de Envio** (inferior) — clique neste **primeiro** para salvar suas respostas no provedor de questionários
2. **Botão Verde de Envio** (superior) — clique neste **segundo** para enviar a sessão cronometrada ao AutoProctor

![Sequência de botões de envio para testes cronometrados mostrando roxo primeiro depois verde](images/taking-tests/submit-buttons-timed.gif)
*Clique no botão roxo primeiro, depois no botão verde*

{% hint style="warning" %}
Se você não clicar no **botão roxo primeiro**, todas as respostas inseridas serão perdidas. Sempre clique no botão roxo de envio antes de clicar no botão verde de envio.
{% endhint %}

{% hint style="info" %}
Os questionários Socratease têm apenas **um botão de envio**, então não há risco de perda de respostas. Consulte [Diferenças do Botão de Envio](candidate-guide/attempting/submit-button.md) para detalhes.
{% endhint %}

## Configuração da Conta Google

Se você está realizando um teste do Google Forms, siga estes passos antes de abrir o link do teste:

{% stepper %}
{% step %}
### Saia de todas as contas Google
Acesse [accounts.google.com/Logout](https://accounts.google.com/Logout) para sair de todas as contas Google no seu dispositivo.
{% endstep %}
{% step %}
### Faça login com a conta correta
Entre novamente com a conta Google que o administrador do teste especificou. Esta é a conta que tem permissão para acessar o formulário do teste.
{% endstep %}
{% step %}
### Abra o link do teste
Navegue até o link do teste fornecido pelo seu administrador.
{% endstep %}
{% endstepper %}
