---
title: "Adicionar Colaboradores aos Seus Testes"
description: "Compartilhe o acesso de gestão de testes com outros membros da equipe usando o recurso de colaboradores do AutoProctor."
---

Os colaboradores podem cogerenciar seus testes visualizando resultados, alterando configurações e acessando todos os dados do teste. Você adiciona colaboradores compartilhando um link exclusivo das Configurações Avançadas do seu teste.

{% hint style="info" %}
Apenas usuários dos planos **Premium** e **Elite** podem adicionar colaboradores. Os colaboradores já devem ser membros da sua [equipe](pricing-account/billing-teams/teams.md). Se alguém ainda não faz parte da sua equipe, convide-o a participar da equipe primeiro.
{% endhint %}

## Como Adicionar um Colaborador

{% embed url="videos/creating-tests/collaborators.mp4" %}
Como adicionar um colaborador ao seu teste
{% endembed %}

{% stepper %}
{% step %}
### Abra as Configurações Avançadas
Navegue até o seu teste e abra a seção **Advanced Settings** na parte inferior da página de configurações.


{% endstep %}
{% step %}
### Copie o Link de Colaboração
Localize a seção de colaboradores, que exibe os colaboradores atuais e fornece um link para adicionar novos. Clique no **link de colaboração** para copiá-lo para a área de transferência.


{% endstep %}
{% step %}
### Compartilhe o Link
Envie o link copiado para o membro da equipe que você deseja adicionar como colaborador.
{% endstep %}
{% step %}
### O Colaborador Aceita
Quando a pessoa clicar no link, ela obterá acesso ao teste imediatamente. Ela aparecerá na lista de colaboradores daquele teste.
{% endstep %}
{% endstepper %}

## Permissões do Colaborador

Uma vez adicionados, os colaboradores recebem **acesso completo de leitura e edição** ao teste:

| Permissão | Acesso |
|---|---|
| Ver resultados | Todos os envios de candidatos e dados de supervisão |
| Alterar configurações | Configurações de tempo, supervisão e avançadas |
| Gerenciar teste | Arquivar, configurar e compartilhar o teste |

{% hint style="warning" %}
O acesso de colaborador é **permanente**. Atualmente não há como remover um colaborador de um teste após adicioná-lo. Compartilhe links de colaboração apenas com pessoas em quem você confia com acesso total ao teste.
{% endhint %}
