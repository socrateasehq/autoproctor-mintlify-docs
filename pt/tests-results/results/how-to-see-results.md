O AutoProctor fornece dois tipos distintos de resultados para cada teste: **resultados do teste** (como os candidatos se saíram) e **resultados de supervisão** (se os candidatos mantiveram a integridade). Conhecer a diferença ajuda a encontrar os dados corretos rapidamente.

![Página de resultados do AutoProctor mostrando a coluna Trust Score para cada candidato](images/getting-started/sample-results.png)
*Página de resultados mostrando a coluna Trust Score*

## Resultados do Teste

Os resultados do teste mostram as respostas e pontuações de cada candidato. A menos que você use os Questionários Socratease, esses resultados aparecem na sua plataforma de questionários original -- não no [painel do AutoProctor](https://www.autoproctor.co/test-admin/home/).

{% hint style="info" %}
A menos que você use Questionários Socratease, não é possível ver os resultados do teste diretamente no AutoProctor. Os resultados do teste aparecem na plataforma onde você criou o teste.
{% endhint %}

| Plataforma de Questionários | Onde Encontrar os Resultados do Teste |
|---|---|
| **Google Forms** | Abra seu Google Form e clique na aba **Respostas** para ver todas as submissões |
| **Microsoft Forms** | Verifique a seção **Respostas** no Microsoft Forms como faria normalmente |
| **Testes IFrame** | Veja os resultados na plataforma que você incorporou no IFrame |
| **Questionários Socratease** | Veja os resultados diretamente no seu [painel do AutoProctor](https://www.autoproctor.co/test-admin/home/) na seção **Resultados** do teste |

{% hint style="info" %}
Se você usa Google Forms e não consegue ver as respostas, consulte o guia de resolução de problemas sobre [respostas do Google Forms não visíveis](tests-results/issues/google-forms-response-not-visible.md).
{% endhint %}

## Resultados de Supervisão

À medida que um candidato realiza o teste, o AutoProctor monitora o ambiente de teste e registra evidências de possíveis irregularidades ou condutas indevidas. Esses dados são compilados em um relatório de supervisão com um [Trust Score](understanding/how-proctoring-works/trust-score.md).

{% hint style="info" %}
Os resultados de supervisão só estão disponíveis quando a supervisão está ativada nas [configurações do teste](tests-results/create/proctoring-settings.md). Testes configurados apenas com temporizador não geram relatórios de supervisão.
{% endhint %}

Para saber como acessar os resultados de supervisão passo a passo, consulte [Onde Posso Ver os Resultados de Supervisão?](tests-results/results/proctoring-results.md).
