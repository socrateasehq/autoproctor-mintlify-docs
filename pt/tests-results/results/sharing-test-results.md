Pode ser necessário compartilhar os resultados dos testes com outros administradores, co-instrutores ou colegas que não criaram o teste original. O método depende da plataforma de questionários que você utiliza.

## Para Google Forms

Quando você compartilha um Google Form com outro usuário, ele pode ter acesso ao mesmo teste do AutoProctor e seus resultados.

{% embed url="videos/settings/timer-proctor-on-gf.mp4" %}
Abrindo o complemento Timer + Proctor em um Google Form compartilhado
{% endembed %}

{% stepper %}
{% step %}
### Compartilhe o Google Form
Compartilhe o link do Google Form com os usuários que precisam de acesso. Certifique-se de que eles tenham permissões de **Editor** no próprio formulário.
{% endstep %}
{% step %}
### Abra o complemento Timer + Proctor
Peça aos outros usuários que abram o complemento **Timer + Proctor** a partir do Google Form compartilhado.
{% endstep %}
{% step %}
### Verifique o acesso
Assim que abrirem o complemento, os outros usuários ficam associados ao mesmo teste. Eles verão o mesmo link do teste e poderão ver os resultados no [painel do AutoProctor](https://www.autoproctor.co/test-admin/home/).
{% endstep %}
{% endstepper %}

{% hint style="info" %}
Os outros usuários devem abrir o complemento Timer + Proctor pelo menos uma vez a partir do Google Form compartilhado. Simplesmente compartilhar o link do Google Form não é suficiente -- eles devem iniciar o complemento para ficarem associados ao teste.
{% endhint %}

## Para Questionários Socratease

Use o recurso **Colaboradores** para conceder a outros usuários acesso ao seu teste e seus resultados.

{% stepper %}
{% step %}
### Abra as configurações do teste
Navegue até o teste no seu [painel do AutoProctor](https://www.autoproctor.co/test-admin/home/) e abra suas configurações.
{% endstep %}
{% step %}
### Adicione colaboradores
Adicione os endereços de e-mail dos usuários aos quais deseja conceder acesso. Consulte [Adicionar Colaboradores](tests-results/access-limits/adding-collaborators.md) para instruções detalhadas.
{% endstep %}
{% endstepper %}

Os colaboradores podem ver resultados, relatórios de supervisão e gerenciar o teste dependendo das permissões que você atribuir.

## Para Todos os Tipos de Teste

Você também pode compartilhar resultados exportando-os:

| Método | Descrição |
|---|---|
| **Exportação para Excel** | Baixe os resultados e compartilhe o arquivo diretamente. Consulte [Exportar para Excel](tests-results/results/export-to-excel.md) |
| **Google Sheets** | Configure a exportação automática para uma planilha Google compartilhada. Consulte [Integração com Google Sheets](tests-results/results/google-sheets-integration.md) |
