---

O Socratease é a plataforma de questionários integrada do AutoProctor, projetada para ser tão fácil quanto o Google Forms, mas desenvolvida especificamente para exames online. Você pode criar questionários, distribuí-los aos candidatos e revisar resultados, tudo a partir de um único painel.

Os principais destaques incluem:
- Um **único [botão de envio](candidate-guide/attempting/submit-button.md)** — sem confusão entre enviar o questionário e o teste supervisionado
- **Criação e visualização de resultados integradas** em um único painel
- Suporte para **13 formatos de perguntas** juntamente com recursos avançados como importações de Excel e bancos de perguntas

## Como Criar um Questionário Socratease

{% embed url="../../videos/socratease/create-soc-test.mp4" %}
Tutorial em vídeo para criar um questionário Socratease
{% endembed %}

{% stepper %}
{% step %}
### Acesse o AutoProctor
Visite [autoproctor.co](https://www.autoproctor.co/) e faça login na sua conta.


{% endstep %}
{% step %}
### Crie um Novo Teste
Clique em **Create Test** e selecione a opção **Socratease Quizzes** como provedor de questionários.


{% endstep %}
{% step %}
### Adicione Perguntas
Adicione suas perguntas usando qualquer um dos [tipos de perguntas suportados](socratease/create-questions/question-types.md). Configure pontos, limites de tempo e outras configurações para cada pergunta.


{% endstep %}
{% step %}
### Configure as Definições
Configure as [configurações do questionário](socratease/settings/quiz-settings.md) incluindo modo de exibição das perguntas, visibilidade dos resultados, aleatorização e mais.


{% endstep %}
{% step %}
### Compartilhe o Teste
Compartilhe o link do teste com seus candidatos. Eles podem acessar o questionário pelo link que você fornecer.


{% endstep %}
{% step %}
### Veja os Resultados
Depois que os candidatos completarem o teste, veja os resultados e relatórios de supervisão no mesmo painel.

![Painel de resultados do AutoProctor mostrando resumo de envios e pontuações dos candidatos](../../images/getting-started/sample-results.png)
*Painel de resultados mostrando envios, pontuações de confiança e notas do teste*
{% endstep %}
{% endstepper %}
