---
title: "Adding Collaborators to Your Tests"
description: "Share test management access with other team members using AutoProctor's collaborator feature."
---

Collaborators can co-manage your tests by viewing results, changing settings, and accessing all test data. You add collaborators by sharing a unique link from your test's Advanced Settings.

{% hint style="info" %}
Only **Premium** and **Elite** plan users can add collaborators. Collaborators must already be members of your [team](pricing-account/billing-teams/teams.md). If someone is not yet on your team, invite them to join your team first.
{% endhint %}

## How to Add a Collaborator

{% embed url="videos/creating-tests/collaborators.mp4" %}
How to add a collaborator to your test
{% endembed %}

{% stepper %}
{% step %}
### Open Advanced Settings
Navigate to your test and open the **Advanced Settings** section at the bottom of the settings page.


{% endstep %}
{% step %}
### Copy the Collaborate Link
Locate the collaborators section, which displays current collaborators and provides a link to add new ones. Click the **collaborate link** to copy it to your clipboard.


{% endstep %}
{% step %}
### Share the Link
Send the copied link to the team member you want to add as a collaborator.
{% endstep %}
{% step %}
### Collaborator Accepts
When the person clicks the link, they gain access to the test immediately. They appear in the collaborators list for that test.
{% endstep %}
{% endstepper %}

## Collaborator Permissions

Once added, collaborators receive **full read and edit access** to the test:

| Permission | Access |
|---|---|
| View results | All candidate submissions and proctoring data |
| Change settings | Timer, proctoring, and advanced settings |
| Manage test | Archive, configure, and share the test |

{% hint style="warning" %}
Collaborator access is **permanent**. There is currently no way to remove a collaborator from a test once added. Share collaborate links only with people you trust with full test access.
{% endhint %}
