Socratease is AutoProctor's built-in quizzing platform, designed to be as easy as Google Forms but purpose-built for online examinations. You can create quizzes, distribute them to candidates, and review results all from a single dashboard.

Key highlights include:
- A **single [submit button](candidate-guide/attempting/submit-button.md)** -- no confusion between submitting the quiz and the proctored test
- **Integrated creation and results** viewing within one dashboard
- Support for **13 question formats** alongside advanced capabilities like Excel imports and question banks

## How to Create a Socratease Quiz

{% embed url="../../videos/socratease/create-soc-test.mp4" %}
Video walkthrough of creating a Socratease quiz
{% endembed %}

{% stepper %}
{% step %}
### Go to AutoProctor
Visit [autoproctor.co](https://www.autoproctor.co/) and log in to your account.


{% endstep %}
{% step %}
### Create a New Test
Click on **Create Test** and select the **Socratease Quizzes** option as your quiz provider.


{% endstep %}
{% step %}
### Add Questions
Add your questions using any of the [supported question types](socratease/create-questions/question-types.md). Configure points, time limits, and other settings for each question.


{% endstep %}
{% step %}
### Configure Settings
Set up your [quiz settings](socratease/settings/quiz-settings.md) including question display mode, result visibility, randomization, and more.


{% endstep %}
{% step %}
### Share the Test
Share the test link with your candidates. They can access the quiz through the link you provide.


{% endstep %}
{% step %}
### View Results
After candidates complete the test, view their results and proctoring reports from the same dashboard.

![AutoProctor results dashboard showing submission summary and candidate scores](../../images/getting-started/sample-results.png)
*Results dashboard showing submissions, trust scores, and test scores*
{% endstep %}
{% endstepper %}
