---
title: "Cómo Crear un Cuestionario Socratease"
description: "Guía paso a paso para crear su primer cuestionario Socratease en AutoProctor."
---

Socratease es la plataforma de cuestionarios integrada de AutoProctor, diseñada para ser tan fácil como Google Forms pero creada específicamente para exámenes en línea. Puede crear cuestionarios, distribuirlos a los candidatos y revisar los resultados, todo desde un solo panel de control.

Los aspectos más destacados incluyen:
- Un **solo [botón de envío](candidate-guide/attempting/submit-button.md)** — sin confusión entre enviar el cuestionario y el examen supervisado
- **Creación y visualización de resultados integradas** dentro de un solo panel de control
- Soporte para **13 formatos de preguntas** junto con funciones avanzadas como importaciones desde Excel y bancos de preguntas

## Cómo Crear un Cuestionario Socratease

{% embed url="../../videos/socratease/create-soc-test.mp4" %}
Tutorial en video para crear un cuestionario Socratease
{% endembed %}

{% stepper %}
{% step %}
### Vaya a AutoProctor
Visite [autoproctor.co](https://www.autoproctor.co/) e inicie sesión en su cuenta.


{% endstep %}
{% step %}
### Cree un Nuevo Examen
Haga clic en **Crear Examen** y seleccione la opción **Cuestionarios Socratease** como su proveedor de cuestionarios.


{% endstep %}
{% step %}
### Agregue Preguntas
Agregue sus preguntas utilizando cualquiera de los [tipos de preguntas admitidos](socratease/create-questions/question-types.md). Configure los puntos, los límites de tiempo y otras opciones para cada pregunta.


{% endstep %}
{% step %}
### Configure los Ajustes
Establezca la [configuración del cuestionario](socratease/settings/quiz-settings.md) incluyendo el modo de visualización de preguntas, la visibilidad de resultados, la aleatorización y más.


{% endstep %}
{% step %}
### Comparta el Examen
Comparta el enlace del examen con sus candidatos. Ellos pueden acceder al cuestionario a través del enlace que usted proporcione.


{% endstep %}
{% step %}
### Vea los Resultados
Una vez que los candidatos completen el examen, vea sus resultados e informes de supervisión desde el mismo panel de control.

![Panel de resultados de AutoProctor mostrando resumen de envíos y puntajes de candidatos](../../images/getting-started/sample-results.png)
*Panel de resultados mostrando envíos, puntajes de confianza y puntajes del examen*
{% endstep %}
{% endstepper %}
