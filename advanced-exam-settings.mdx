Advanced settings give you control over how candidates log in, who can access the test, what candidates see before and after it, and how results are shared. They live in the **Access & login**, **Before the test** and **After the test** sections of a test's **Settings**.

## Where to Find Each Setting

Go to your [**Tests**](https://www.autoproctor.co/test-admin/home/) page and click **Settings** next to the test. Then choose a section from the list of sections.

| Section | What you set there | Read more |
|---|---|---|
| **General** | Test title, **Max attempts per candidate**, **Auto-resume**, **Close test for submissions**, **Hide from my dashboard** | [Maximum Attempts](/maximum-exam-attempts), [Resuming Test Attempts](/resume-exam-attempts), [Closing, Hiding and Deleting Tests](/archive-and-delete-exams) |
| **Quiz behaviour** | Socratease quizzes only. Opens the quiz's own settings | [Socratease Quiz Settings](/socratease-quiz-settings) |
| **Timer** | Duration and start window | [Timer Settings](/timer-settings) |
| **Proctoring** | What gets tracked and who is informed | [Proctoring Settings](/proctoring-settings) |
| **Access & login** | **Login providers**, **Login restrictions**, **Unique test URLs**, **iFrame height**, **iFrame width**, **Query string** | This page |
| **Before the test** | **Collect candidate details**, **Show additional instructions** | This page |
| **After the test** | What candidates see on submission, **Send results to a Google Sheet** | This page |

## Access & Login

The **Access & login** section controls who can open the test link and how they sign in. Which controls you see depends on the quiz provider of the test.

| Control | Socratease Quizzes | Google Forms | Microsoft Forms | IFrame Tests |
|---|---|---|---|---|
| **Login providers** | Yes | No | No | Yes |
| **Login restrictions** | Yes | Yes | Yes | Yes |
| **Unique test URLs** | Yes | Yes | Yes | Yes |
| **iFrame height** and **iFrame width** | No | No | No | Yes |
| **Query string** | No | Yes | Yes | Yes |

### Login Providers

Choose which authentication methods candidates can use to sign in to your test:

| Provider | Description | Availability |
|---|---|---|
| **Google** | Sign in with a Google account | Always used for Google Forms tests. Optional for Socratease and IFrame tests. |
| **Microsoft** | Sign in with a Microsoft account | Always used for Microsoft Forms tests. Optional for Socratease and IFrame tests. |
| **Email** | Sign in with any email address | Socratease and IFrame tests only. |

Google Forms and Microsoft Forms tests always use the login of their own quiz platform, so **Login providers** is not shown for them. For Socratease and IFrame tests, tick one or more providers, including Google and Microsoft login.

For more details on how each login method works, see [Candidate Login Methods](/candidate-login-methods).

### Login Restrictions

**Login restrictions** limit which candidates can take your test based on their email address or domain. Enter the allowed domains or addresses in the field, separated by commas.

- **Restrict by domain**: allow only candidates with email addresses from specific domains (e.g., `@university.edu`)
- **Restrict by email**: allow only specific email addresses to access the test

For detailed instructions, see [Restricting by Email](/restrict-access-by-email).

### Unique Test URLs (Elite)

By default, all candidates share a single test link, which could be forwarded to unintended recipients. Turning on **Unique test URLs** lets you generate one link per candidate, so only the people you share links with can take the test.

Turning it on forces email login: under **Login providers**, only **Email** stays ticked. Once the setting is saved, a **Generate unique links** link appears under the switch and opens the page where you create the links.

<Note>
Unique test URLs are an Elite feature and work with Socratease Quizzes and IFrame Tests. Do not turn the switch on for a Google Forms or Microsoft Forms test, because those tests need the sign-in of their own platform. See [Inviting Candidates via Email](/invite-candidates-via-email) for the full process and [Elite Features](/elite-plan-features) for plan details.
</Note>

### IFrame Height and Width

When your test is embedded as an iframe inside AutoProctor, **iFrame height** lets you adjust the height (in pixels) of that iframe to match your test content. The default is 1764px. Increase it if your test content is getting cut off or candidates have to scroll within the iframe, or decrease it to remove extra whitespace.

**iFrame width** sets the maximum width of the area that holds your test, in pixels. Both fields appear only for IFrame tests.

### Query String

The **Query string** is appended to the test URL when the test loads, for example `a=b&c=d`. See [IFrame Query Arguments](/iframe-query-arguments) for how to use it.

## Before the Test

The **Before the test** section controls what candidates see on the instructions page, which is the page your test link opens before the quiz.

| Setting | Plan | What it does |
|---|---|---|
| **Collect candidate details** | Premium | Asks candidates for custom information before the test starts, such as phone number, college name, or any custom question |
| **Show additional instructions** | Elite | Shows your own instructions on the instructions page, next to the standard ones |

### Collect Candidate Details (Premium)

These fields appear on the instructions page, and every field is required. The collected data is available in results and exports.

<Note>
You can add up to 10 custom information fields per test.
</Note>

### Show Additional Instructions (Elite)

Add custom instructions to the candidate instructions page. They are shown to candidates before they start the test, and can give specific guidelines, rules, or context for your test. The text is plain text of up to 200 words.

<Note>
Additional instructions are an Elite feature. See the [Instructions Page for Candidates](/candidate-instructions-page) for more on what candidates see before starting.
</Note>

## After the Test

The **After the test** section controls what candidates see when they submit, and where results go.

### On Test Completion (Premium)

By default, all users see the standard AutoProctor completion page. Premium and above users can customize this with two additional options:

| Option | Description |
|---|---|
| **Show the default message** | Display the standard AutoProctor completion page (available on all plans) |
| **Show a custom message** | Display your own HTML message to candidates (e.g., "Thank you for completing the assessment!"). Basic HTML of up to 1,000 characters |
| **Redirect to a URL** | Send candidates to an external page after submission (e.g., your company's website or a feedback form). The URL must start with `http://` or `https://` |

### Send Results to a Google Sheet (Premium)

Automatically write test results to a Google Sheet by pasting the sheet's link into **Send results to a Google Sheet**. For Socratease quizzes, both proctoring results and quiz scores are exported. For non-Socratease quizzes, only proctoring results are included.

<Warning>
This works only with proctoring on. While proctoring is off, nothing is written to the sheet, and saving the settings removes the link.
</Warning>

For setup instructions, see [Google Sheets Integration](/write-results-to-google-sheets).

## Collaborators

Add colleagues as collaborators on your test so they can edit settings and view results. The collaborators card at the top of the Settings page lists everyone on the test. Click **Manage** on that card to copy the **Collaborate link**, remove a collaborator, or set the test's primary admin.
