Advanced settings control how candidates log in, who can access the test, what candidates see before and after it, and where results go. They live in the **Access & login**, **Before the test** and **After the test** sections of a test's **Settings**.

## Where to Find Each Setting

On your [**Tests**](https://www.autoproctor.co/test-admin/home/) page, click **Settings** next to the test, then choose a section.

| Section | What you set there | Read more |
|---|---|---|
| **General** | Test title, **Max attempts per candidate**, **Auto-resume**, **Close test for submissions**, **Hide from my dashboard** | [Maximum Attempts](/maximum-exam-attempts), [Resuming Test Attempts](/resume-exam-attempts), [Closing, Hiding and Deleting Tests](/archive-and-delete-exams) |
| **Quiz behaviour** | Socratease quizzes only. Opens the quiz's own settings | [Socratease Quiz Settings](/socratease-quiz-settings) |
| **Timer** | Duration and start window | [Timer Settings](/timer-settings) |
| **Proctoring** | What gets tracked and who is informed | [Proctoring Settings](/proctoring-settings) |
| **Access & login** | **Login providers**, **Login restrictions**, **Unique test URLs**, **iFrame height**, **iFrame width**, **Query string** | This page |
| **Before the test** | **Collect candidate details**, **Show additional instructions** | This page |
| **After the test** | What candidates see on submission, **Send results to a Google Sheet** | This page |

## Access & Login

The controls you see depend on the quiz provider of the test.

| Control | Socratease Quizzes | Google Forms | Microsoft Forms | IFrame Tests |
|---|---|---|---|---|
| **Login providers** | Yes | No | No | Yes |
| **Login restrictions** | Yes | Yes | Yes | Yes |
| **Unique test URLs** | Yes | Yes | Yes | Yes |
| **iFrame height** and **iFrame width** | No | No | No | Yes |
| **Query string** | No | Yes | Yes | Yes |

### Login Providers

Choose which methods candidates can use to sign in to your test:

| Provider | Where it is used |
|---|---|
| **Google** | Always used for Google Forms tests. Optional for Socratease and IFrame tests |
| **Microsoft** | Always used for Microsoft Forms tests. Optional for Socratease and IFrame tests |
| **Email** | Socratease and IFrame tests only |

See [Candidate Login Methods](/candidate-login-methods) for how each login method works.

### Login Restrictions

**Login restrictions** limit the test to specific email addresses or domains, such as `@university.edu`. Enter them in the field, separated by commas. The field holds up to 30 entries, so for a longer list use [unique test URLs](#unique-test-urls-elite).

For detailed instructions, see [Restricting by Email](/restrict-access-by-email).

### Unique Test URLs (Elite)

By default, all candidates share one test link, which could be forwarded to unintended recipients. **Unique test URLs** gives each candidate their own link, so only the people you share links with can take the test.

Turning it on forces email login. Once the setting is saved, a **Generate unique links** link appears under the switch.

<Note>
Unique test URLs work with Socratease Quizzes and IFrame Tests. Do not turn the switch on for a Google Forms or Microsoft Forms test, because those tests need the sign-in of their own platform. See [Inviting Candidates via Email](/invite-candidates-via-email) for the full process and [Elite Features](/elite-plan-features) for plan details.
</Note>

### IFrame Height and Width

**iFrame height** sets the height of the embedded test in pixels. The default is 1764. Increase it if your test content is cut off, or decrease it to remove extra whitespace.

**iFrame width** sets the maximum width of the area that holds your test. Both fields appear only for IFrame tests.

### Query String

The **Query string** is appended to the test URL when the test loads, for example `a=b&c=d`. See [IFrame Query Arguments](/iframe-query-arguments) for how to use it.

## Before the Test

These settings change the instructions page, which is the page your test link opens before the quiz.

| Setting | Plan | What it does |
|---|---|---|
| **Collect candidate details** | Premium | Asks candidates for custom information before the test starts, such as phone number, college name, or any custom question |
| **Show additional instructions** | Elite | Shows your own instructions on the instructions page, next to the standard ones |

### Collect Candidate Details (Premium)

You can add up to 10 fields per test, and every field is required. The collected data is available in results and exports.

<Frame>
  <img src="/images/advanced-exam-settings/candidate-details-three-fields.png" alt="Collect candidate details switched on, with three fields added" />
</Frame>

### Show Additional Instructions (Elite)

The instructions are plain text of up to 200 words. See the [Instructions Page for Candidates](/candidate-instructions-page) for what candidates see before starting.

## After the Test

### On Test Completion (Premium)

All plans show the standard AutoProctor completion page. Premium and above can choose one of two other options:

| Option | Description |
|---|---|
| **Show the default message** | Display the standard AutoProctor completion page (available on all plans) |
| **Show a custom message** | Display your own message to candidates. Basic HTML of up to 1,000 characters |
| **Redirect to a URL** | Send candidates to an external page after submission, such as a feedback form. The URL must start with `http://` or `https://` |

<Frame>
  <img src="/images/advanced-exam-settings/on-test-completion.png" alt="The three completion options, with Show a custom message selected" />
</Frame>

### Send Results to a Google Sheet (Premium)

Paste a sheet's link into **Send results to a Google Sheet** to write test results to it automatically. Socratease quizzes export both proctoring results and quiz scores. Other quizzes export proctoring results only.

<Warning>
This works only with proctoring on. While proctoring is off, nothing is written to the sheet, and saving the settings removes the link.
</Warning>

For setup instructions, see [Google Sheets Integration](/write-results-to-google-sheets).

## Collaborators

Collaborators can edit the test's settings and view its results. Click **Manage** on the collaborators card at the top of the Settings page to copy the **Collaborate link**, remove a collaborator, or set the test's primary admin.
