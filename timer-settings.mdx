Timer settings let you control when candidates can start a test, how long they have to complete it, and what happens when time runs out. They live in the **Timer** section of a test's **Settings**.

<Note>
The times you set are in your local timezone. AutoProctor handles all timezone conversions automatically. If your candidates are in a different timezone, they will see the correct local time on their end.
</Note>

## How to Configure Timer Settings

<Steps>
  <Step title="Open the Timer Section">
    Go to your [**Tests**](https://www.autoproctor.co/test-admin/home/) page, click **Settings** next to the test, and choose **Timer** from the list of sections.
  </Step>
  <Step title="Turn the Timer On">
    Turn on the switch at the top right of the **Timer** section. While the switch is **Off**, candidates can take as long as they need and no time checks apply.
  </Step>
  <Step title="Set the Duration">
    Under **How long do candidates get?**, enter the **Duration** in minutes. The countdown starts when the test loads and the candidate sees the questions.
  </Step>
  <Step title="Choose What Happens When Time Runs Out (Optional)">
    Tick **Submit automatically when time runs out** to submit the test when the duration ends. If you leave it unticked, candidates get unlimited time to submit after the timer runs out.

    <Warning>
    For non-Socratease quizzes, auto-submit only submits the proctoring session, not the quiz answers. If a candidate hasn't manually submitted their answers, **all responses will be lost**. For Socratease quizzes, both answers and proctoring data are submitted automatically.
    </Warning>
  </Step>
  <Step title="Set a Start Window (Optional)">
    Under **When can candidates start?**, pick a date and time for either or both of these:
    - **Cannot start before**: the earliest date and time a candidate can start
    - **Cannot start after**: the latest date and time a candidate can start

    Leave both empty to let candidates start any time. If you set a date without a time, midnight is used as the default.
  </Step>
  <Step title="Save">
    Click **Save settings**.
  </Step>
</Steps>

## More Options

Click **More options** at the bottom of the **Timer** section to show two less common settings. Both need a **Cannot start after** date to be set first.

| Setting | What it does |
|---|---|
| **Hard stop** | A time on the **Cannot start after** date. Everyone still taking the test is submitted at this time |
| **Late-start grace period** | Extra minutes a candidate has to start after the **Cannot start after** time. The minimum is 5 |

### Hard stop

A **Hard stop** shortens the time of candidates who start late. For example, if the duration is 30 minutes and the Hard stop is 12:30 PM, a candidate starting at 12:15 PM gets only 15 minutes.

The Hard stop cannot be earlier than **Cannot start before** or **Cannot start after**.

### Late-start grace period

The grace period gives candidates time to complete the demo test and set up their device. AutoProctor adds a default 5-minute grace period when start and end times are set.

<Note>
The grace period does not apply to the **Hard stop**.
</Note>

## Timer Settings Reference

| Setting | Description | Default |
|---|---|---|
| **Duration** | Maximum time for a test attempt, in minutes | No limit |
| **Submit automatically when time runs out** | Submit when the duration ends | Off |
| **Cannot start before** | Earliest start date and time | No restriction |
| **Cannot start after** | Latest start date and time | No restriction |
| **Hard stop** | Time at which everyone still in the test is submitted | Not set |
| **Late-start grace period** | Extra minutes to start after **Cannot start after** | 5 min (when times are set) |

<Note>
If a Socratease quiz shows questions **one-by-one with no question navigation**, each question is timed separately. **Duration**, auto-submit and **Hard stop** do not apply to that quiz, but the start window still does. You can change the display mode from **Quiz behaviour** in the test's Settings.
</Note>
