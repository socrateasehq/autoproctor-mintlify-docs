AutoProctor loads your quiz inside an iframe. The **Query string** field lets you add query parameters to the quiz link, for example to force a language or enable embedded mode, without modifying the original link.

The field appears for Google Forms, Microsoft Forms and IFrame tests. Socratease quizzes do not have it.

## How to Add Query Arguments

<Steps>
  <Step title="Open the Access & Login Section">
    Go to your [**Tests**](https://www.autoproctor.co/test-admin/home/) page, click **Settings** next to the test, and choose **Access & login**.
  </Step>
  <Step title="Enter Your Query Arguments">
    Type your parameters in the **Query string** field, in the format `key1=val1&key2=val2`. Then click **Save settings**.
  </Step>
</Steps>

<Frame>
  <img src="/images/iframe-query-arguments/query-string.png" alt="The Query string field with hl=en entered" />
</Frame>

<Note>
Do not include the `?` prefix in your query arguments. AutoProctor adds it automatically when constructing the link.
</Note>

## How It Works

AutoProctor adds your parameters to the quiz link when it loads the iframe.

| Original link | Query string | Link AutoProctor loads |
|---|---|---|
| `www.website.com` | `key1=val1&key2=val2` | `www.website.com?key1=val1&key2=val2` |

If the quiz link already has parameters, they are kept. When one of your parameters has the same name as an existing one, your value is used.

## Common Parameters

| Parameter | Purpose | Example Use Case |
|---|---|---|
| `hl=en` | Set the language to English. Use `hl=fr` for French | Render a Google Form in English for international candidates |
| `embedded=true` | Force embedded mode | Ensure certain platforms display correctly inside the iframe |
